### How to Run this Project:

1. Extract this ZIP file.
2. Open terminal in `angular-portfolio` directory.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Put your picture as `profile.jpg` inside the `public/` directory (or replace the placeholder).
5. Start development server:
   ```bash
   npm start
   # or
   ng serve
   ```
6. Open your browser and navigate to `http://localhost:4200/`.
